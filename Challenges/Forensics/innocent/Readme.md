# ZIP Deception Challenge (CTF - Forensics)

## Overview
This challenge demonstrates how files can be manipulated to **hide malicious or secret data inside seemingly normal archives**.

A ZIP file is created with innocent-looking content, but it secretly contains **hidden encoded data appended to it**.

Your goal is to uncover the hidden flag.

---

##  How to Run

### Step 1: Give Permission
```bash
chmod +x generate.sh
```
### Step 2: Run
```bash
./generate.sh
```
After Execution you get /work/innocent.zip
