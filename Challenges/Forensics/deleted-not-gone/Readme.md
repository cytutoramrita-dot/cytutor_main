# Digital Forensics - Deleted File Recovery (CTF)

## Overview
This project demonstrates a basic **digital forensics concept** — how deleted files are not actually gone from a disk and can still be recovered.

The script creates a disk image, writes a secret file, deletes it, and leaves traces behind for forensic analysis.
